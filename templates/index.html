    System Design

    Production Architecture

    Built with high-availability standards, automated data validation, and reproducible pipelines.

    Machine Learning Pipeline

    Scikit-learn random forest classifier optimized with GridSearch cross-validation. Employs imputation, target-encoding, and robust feature scaling for credit scoring.

    Security & Data Protection

    No PII (Personally Identifiable Information) persisted. Strict schema validation via Marshmallow, SQL parameterization, rate limiting, and automated origin CORS safeguards.

    Serving Infrastructure

    Served via Flask 3.x and Gunicorn on Render container infrastructure with automated health probing, in-memory caching, response compression, and Swagger OpenAPI documentation.
